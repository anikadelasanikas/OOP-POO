Clases y objetos:
Ejemplo de programación orientada a objetos (POO) en Python.
Como funciona:
- Define una clase `Objeto` (usada como Producto) con nombre, precio y cantidad.
- Crea un producto:
  Ejemplo:
  Una zapatilla de 30 € con 5 unidades.
- Muestra la información del producto por pantalla.
 Que aprendi:
- Qué es una clase y cómo se define (con `class`)
- El constructor `__init__` para dar valores iniciales
- Métodos
- Crear objetos a partir de una clase
- Acceder a los atributos de un objeto
